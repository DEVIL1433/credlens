📶 Capture mode

            

              
              
              
            

            
checking…

            
            
Normal mode watches this laptop's own traffic on Wi-Fi/Ethernet. Hotspot mode watches the devices joined to this laptop's Mobile Hotspot — turn the hotspot on in Windows Settings, connect the device to it, then pick Hotspot mode. Picking a mode yourself turns auto-switch off: you stay in control, the app never moves capture on its own. The hotspot usually lives at 192.168.137.1.

          

          
Auto-resume
CredLens remembers only which adapter you picked (credlens-settings.json) and re-arms live capture on it after a restart. Captured data is never saved to disk by the app.

          
What it can see
Plain-text traffic on the adapter you capture on — this machine's own traffic in full. Other devices appear by name/IP from the LAN, but their traffic isn't visible from a normal Wi-Fi adapter.

          
What it catches
Website logins (forms, JSON, Basic Auth), exposed session cookies, API keys and bearer tokens in web traffic — plus plaintext protocol logins: FTP, mail (POP3 / IMAP / SMTP), Telnet and MQTT.

          
What it can't see
Anything inside HTTPS. That invisibility is exactly the protection HTTP lacks — and the whole point of this tool.

          
Behaviour
CredLens never sends traffic on your behalf — it only watches (naming devices uses the same standard NetBIOS/mDNS lookups your own OS makes), same as Wireshark.
